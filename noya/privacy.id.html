Cara Noya menangani datamu

Penjelasan sederhana tentang apa yang dilakukan aplikasi. Ini bukan nasihat hukum dan tidak mengklaim kepatuhan pada undang-undang tertentu.

  • Disimpan di perangkatmu: jawaban onboarding, catatan harian (darah, nyeri, suasana hati, tidur, stres), penghitung puasa, catatan pribadi opsional, dan pengaturan. Semuanya disimpan dalam database yang terenkripsi di perangkat.
  • Tidak dikirim ke mana pun: aplikasi tidak memiliki kode analitik, jaringan iklan, atau pelacakan, dan tidak mengirim data ini ke server mana pun.
  • Tautan pasangan: hanya berisi yang kamu pilih untuk dibagikan hari itu: fase siklus dengan bahasa sederhana (misalnya "hari haid"), opsional suasana hati, gejala yang kamu pilih, dan hanya jika kamu menyalakannya, perkiraan rentang haid berikutnya. Tidak pernah berisi kalender, riwayat, catatan, atau perkiraan kesuburan. Tidak dikirim atau disimpan di server mana pun, dan berhenti berlaku setelah hari itu.
  • Hapus Data Saya / Panic Wipe (Pengaturan) menimpa database tersimpan tiga kali, lalu menghapusnya beserta kuncinya. Jika kamu lupa kata sandi atau menghapus data, Noya tidak bisa memulihkannya.
  • File cadangan: jika kamu mengekspor cadangan, file disimpan di tempat yang kamu pilih dan dienkripsi dengan kata sandi cadangan yang kamu ketik. Noya tidak mengunggahnya. Tanpa kata sandi itu, file tidak bisa dibuka.
  • Anak-anak: Noya tidak mengumpulkan data anak. Tidak ada akun, dan tidak ada nama, foto, sekolah, atau email yang diminta. Semua disimpan lokal di perangkat. Mode Remaja mematikan fitur pasangan.
  • Iklan: Noya berisi iklan. Pengguna gratis dapat melihat satu kartu iklan kecil per hari di bawah kalender, berisi kartu Noya (misalnya tentang Noya Pro atau ajakan ke teman) atau produk dari merek mitra terpilih (pembalut, perawatan kulit, vitamin, teh herbal). Iklan ini statis, bukan dari jaringan iklan pihak ketiga atau SDK iklan, tidak memakai ID iklan, dan tidak dipersonalisasi: aplikasi tidak mengirim data siklus, profil, atau pengenal apa pun untuk memilih kartu. Tautan di kartu hanya terbuka di browsermu saat kamu mengetuknya. Iklan tidak ditampilkan untuk pengguna Pro atau Lifetime, di Mode Remaja, maupun Mode Samar, dan bisa dilewati hari itu dengan membagikan Noya ke teman atau dihilangkan dengan Noya Pro. Kami tidak mengizinkan iklan judi, pinjaman, alkohol, rokok, atau tes kehamilan.
  • Pengingat: jika kamu menyalakan pengingat, Noya meminta izin notifikasi Android. Pengingat dijadwalkan di perangkatmu sendiri, tanpa server, dan teksnya netral saat Mode Samar aktif. Kamu bisa mematikannya di Pengaturan atau di pengaturan ponsel kapan saja.
  • Tautan luar: tautan bantuan di chat membuka findahelpline.com di browsermu, di luar Noya.
